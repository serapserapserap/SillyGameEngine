## Silly Game Engine

This project is currently a work in progress and isn't in a usable state yet (hopefully I will get it to the point of usability soon). The project aims at being a game library which assists in game development without making game developers have to play tug of war with the tools they're using to build the game while still speeding up the development process by abstracting out systems such as I/O, networking and raw graphics library calls.
